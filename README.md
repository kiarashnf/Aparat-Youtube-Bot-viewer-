## 🇬🇧 English

A Python experiment exploring HTTP requests, session management, multithreading, and YouTube Live URL interactions.

### ✨ Features
- ⚡ Multithreaded execution
- 🌐 HTTP session management
- 🎭 Random User-Agent headers
- 🍪 Cookie generation
- ⏱️ Configurable delays
- 📝 Logging system

### 🛠️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
pip install requests fake-useragent
```

### ▶️ Run

```bash
python viewaparat.py
```

### ⚙️ Configuration

```python
NUM_VIEWS = 100
MAX_THREADS = 10
DELAY_MIN = 1
DELAY_MAX = 5
```
